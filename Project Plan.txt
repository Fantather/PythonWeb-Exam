=== Приложение "core" ===
Используется для абстрактных классов, их будут реализовать в разных модулях проекта, все модули смогут использовать эти абстракции
На пример модели и методы взаимодействия с User и абстрактный класс для взаимодействия с датами

---Файлы---
core/models.py - User и абстрактные классы


=== Приложение "forum" ===
Всё что касается именно форума - посты, категории, темы, комментарии, рейтинг

---Файлы---
forum/models.py - схемы таблиц форума и простые методы внутри классов таблиц
forum/managers.py - кастомные запросы к БД для форума, на пример Фильтрация, агрегация, оптимизация JOIN запросов
forum/services.py - функции взаимодействия моделей форума друг с другом, чтобы сохранить контроллеры (Views) чистыми
