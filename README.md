# Проект: Форум

## Цель

В рамках проекта вам нужно создать веб-приложение — форум для обсуждения различных тем. Форум организован по категориям, каждая из которых содержит набор постов. Каждый пост является отдельным обсуждением, где пользователи могут взаимодействовать друг с другом.
