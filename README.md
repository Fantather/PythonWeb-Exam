# Проект: Форум

## Цель

В рамках проекта вам нужно создать веб-приложение — форум для обсуждения различных тем. Форум организован по категориям, каждая из которых содержит набор постов. Каждый пост является отдельным обсуждением, где пользователи могут взаимодействовать друг с другом.

## Структура сайта

### 1. Главная страница

- [x] Создать главную страницу, которая содержит карточки с сообществами.
  - Структура карточки сообщества:
    - [x] Название сообщества
    - [ ] Описание сообщества
    - [x] Иконка (изображение) сообщества (опционально; если нет изображения, использовать стандартное).
- [ ] Добавить кнопку создания сообщества:
  - [x] Настроить редирект на страницу регистрации (если пользователь не авторизован).
  - [ ] Настроить переход на страницу с формой создания сообщества (если пользователь авторизован).

### 2. Страница регистрации

- [x] Реализовать страницу с формой регистрации:
  - [x] Имя и фамилия пользователя
  - [x] Никнейм пользователя (должен быть уникальным)
  - [x] Электронная почта
  - [x] Дата рождения

### 3. Страница авторизации

- [x] Реализовать страницу с формой авторизации:
  - [x] Никнейм(у нас email)
  - [x] Пароль

### 4. Страница пользователя (Профиль)

- [x] Создать страницу профиля пользователя:
  - [x] Отображение текущей информации о пользователе.
  - [ ] Добавить возможность изменить данные (никнейм, имя, дату рождения, пароль, аватарку).

### 5. Страница сообщества

- [x] Создать страницу сообщества, которая содержит карточки с постами.
  - [ ] Добавить возможность удалить сообщества (при этом должны удаляться также все посты и комментарии к этим постам).
  - Структура карточки поста:
    - [x] Автор
    - [x] Текст поста
    - [x] Кнопка "Перейти к обсуждению" (onclick?)
    - [x] Лайки
    - [x] Дата создания

### 6. Страница поста

- [ ] Создать страницу конкретного поста с набором комментариев:
  - [ ] Отображение самого поста (структура аналогична карточке выше).
  - [ ] Предоставить возможность автору удалить свой пост.
  - Структура комментария под постом:
    - [ ] Автор
    - [ ] Текст комментария
    - [ ] Лайки
    - [ ] Дата создания
    - [ ] Предоставить возможность удалить комментарий (только если он принадлежит текущему автору).
