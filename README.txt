# Проект: Форум

## Цель
В рамках проекта вам нужно создать веб-приложение — форум для обсуждения различных тем. Форум организован по категориям, каждая из которых содержит набор постов. Каждый пост является отдельным обсуждением, где пользователи могут взаимодействовать друг с другом.

## Структура сайта

### 1. Главная страница
- [ ] Создать главную страницу, которая содержит карточки с категориями.
  - Структура карточки категории:
    - [ ] Название категории
    - [ ] Описание категории
    - [ ] Иконка (изображение) категории (опционально; если нет изображения, использовать стандартное).
- [ ] Добавить кнопку создания категории:
  - [ ] Настроить редирект на страницу регистрации (если пользователь не авторизован).
  - [ ] Настроить переход на страницу с формой создания категории (если пользователь авторизован).

### 2. Страница регистрации
- [ ] Реализовать страницу с формой регистрации:
  - [ ] Имя и фамилия пользователя
  - [ ] Никнейм пользователя (должен быть уникальным)
  - [ ] Электронная почта
  - [ ] Дата рождения

### 3. Страница авторизации
- [ ] Реализовать страницу с формой авторизации:
  - [ ] Никнейм
  - [ ] Пароль

### 4. Страница пользователя (Профиль)
- [ ] Создать страницу профиля пользователя:
  - [ ] Отображение текущей информации о пользователе.
  - [ ] Добавить возможность изменить данные (никнейм, имя, дату рождения, пароль, аватарку).

### 5. Страница категории
- [ ] Создать страницу категории, которая содержит карточки с постами.
  - [ ] Добавить возможность удалить категорию (при этом должны удаляться также все посты и комментарии к этим постам).
  - Структура карточки поста:
    - [ ] Автор
    - [ ] Текст поста
    - [ ] Кнопка "Перейти к обсуждению"
    - [ ] Лайки
    - [ ] Дата создания

### 6. Страница поста
- [ ] Создать страницу конкретного поста с набором комментариев:
  - [ ] Отображение самого поста (структура аналогична карточке выше).
  - [ ] Предоставить возможность автору удалить свой пост.
  - Структура комментария под постом:
    - [ ] Автор
    - [ ] Текст комментария
    - [ ] Лайки
    - [ ] Дата создания
    - [ ] Предоставить возможность удалить комментарий (только если он принадлежит текущему автору).
